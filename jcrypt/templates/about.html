About

JCRYPT

A practical encryption, decryption & hashing toolkit.

{% endif %}

JCRYPT is an educational cybersecurity project for exploring how modern and classical cryptography, hashing, and text encoding actually work. It bundles authenticated encryption (AES-GCM, ChaCha20-Poly1305, Fernet), five classical ciphers, twelve hash algorithms, and four text encodings behind one small, local web interface.

How it works

The interface is plain HTML, CSS, and vanilla JavaScript talking to a Flask backend over a small JSON API. Every operation — encrypting, decrypting, hashing, encoding — runs entirely inside your local Flask process using well-vetted Python libraries: the cryptography package for AES, ChaCha20-Poly1305, and Fernet, and the standard library's hashlib for digests. No cryptographic primitive is implemented by hand.

What JCRYPT is not

  • Not a place to store secrets — nothing is written to disk or a database.
  • Not a password manager, VPN, or production security product.
  • Not a place to trust classical ciphers (Caesar, ROT13, Atbash, Vigenere, Affine) for real confidentiality — they exist purely to teach the ideas behind substitution ciphers.

Design principles

  • Stateless by default — refreshing the page clears everything.
  • Keys are generated with Python's secrets module, never random.
  • Modern authenticated modes only — no unauthenticated or ECB-mode AES.
  • Clear, non-alarming error messages for bad input, wrong keys, or malformed ciphertext.
